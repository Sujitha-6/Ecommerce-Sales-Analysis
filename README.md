# E-Commerce Sales Analysis Using SQL and Python

## Project Overview
This project focuses on analyzing Brazilian e-commerce sales data to understand sales performance, customer behaviour, product categories, payment methods, seller performance, and delivery efficiency.

The project uses SQL for data analysis and Python for data visualization.

## Dataset
- Dataset: Brazilian E-Commerce Public Dataset by Olist
- Database: MySQL
- Number of tables: 9
- Total records: 1,550,920

## Technologies Used
- MySQL
- SQL
- MySQL Workbench
- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code

## SQL Concepts Used
- SELECT and WHERE
- Aggregate Functions
- GROUP BY and HAVING
- INNER JOIN and LEFT JOIN
- Subqueries
- Window Functions
- Data Cleaning

## Business Analysis
The project covers:
1. Monthly Sales Trend
2. Top 10 Product Categories by Revenue
3. Customer Distribution by State
4. Payment Method Analysis
5. Top 10 Sellers by Revenue
6. Average Delivery Time
7. Late Delivery Analysis
8. Review Score Analysis

## Python Visualizations
Five visualizations were created:
- Monthly Sales Trend
- Top 10 Product Categories by Revenue
- Payment Method Distribution
- Customer Distribution by State
- Top 10 Sellers by Revenue

## Key Findings
- Health and Beauty was the highest-revenue product category among the top 10.
- Credit card was the most popular payment method.
- São Paulo had the highest number of customers.
- Average delivery time was 12.50 days.
- Late delivery rate was 8.11%.
- November 2017 recorded the highest monthly revenue in the analyzed period.
